## 1. Cambios

### Hilos
- `utility::getIdealThreadCount` lee `SOURCETRAIL_INDEXER_THREADS` (prioridad),
  cap headless `min(cores, 2)` y GUI `cores-1` en Windows.
- `Project::buildIndex` prioriza el env sobre el setting guardado y loguea
  `Using N indexer thread(s).`

### Heap JVM
- `utility::getJavaHeapSizeMb`: `SOURCETRAIL_JAVA_HEAP` o 25 % de RAM física,
  acotado a **256..2048 MB**.
- `JavaEnvironmentFactory` usa `-Xms`/`-Xmx` calculados; ya no está fijo en 2048 MB.

### CLI
- `--refresh=all|updated` (default **updated**), `--threads=N`, `--java-heap=MB`,
  `--python-shallow`, `--help`.
- El CLI desactiva el índice full‑text en memoria (`SOURCETRAIL_FTS=0`) salvo que el
  usuario lo active; la GUI mantiene el default.

### Python y FTS
- `SourceGroupSettingsPythonEmpty`: `SOURCETRAIL_PYTHON_SHALLOW=1` agrega `--shallow`.
- `PersistentStorage::getFullTextSearchLocations`: retorna vacío con `SOURCETRAIL_FTS=0`.

### Documentación
- Nuevo `BUILD_EMBEDDED.md` con perfil, variables y flags.
