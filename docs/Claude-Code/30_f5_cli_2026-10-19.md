## 1. Alcance

Primer corte de F5 en la costura del CLI: las opciones del ejecutable
`sourcetrail_cli` dejan de estar codificadas en `main.cpp` y pasan a un
registro con inversa, alimentado por un manifiesto del `PluginHost`.

La GUI (acciones, páginas, listeners) sigue pendiente; este corte es
deliberadamente headless y testeable sin Qt.

---

## 2. Cambios

### 2.1 `CliOptionRegistry`

`src/lib/utility/commandline/CliOptionRegistry.h/.cpp`:

- `CliParseResult`: `refreshAll`, `help`, variables de entorno y argumentos
  posicionales. No depende de `RefreshMode` ni de `Application`, así que se
  puede probar aislado.
- `CliOption`: interfaz con `name`, `help`, `matches(argument)` y
  `apply(argument, result, error)`.
- `FunctionalCliOption`: implementación con dos `std::function`, para declarar
  opciones sin crear una clase por cada una.
- `CliOptionRegistry`: `addOption`, `removeOption`, `options`, `parse`.
- `cliOptionRegistry()`: instancia de proceso, deliberadamente filtrada para
  que el plugin y el parser vean siempre el mismo registro.

### 2.2 `CliPlugin`

`src/lib/project/CliPlugin.*`:

- manifiesto `cli-options`, `unloadable=false`;
- `apply` registra cinco opciones dentro de un `ctx.effect`:
  `--help/-h`, `--refresh=all|updated`, `--threads=N`, `--java-heap=MB` y
  `--python-shallow`;
- el dispose las elimina en orden inverso.

### 2.3 `src/cli/main.cpp`

- llama a `st::plugin::ensureCliPluginLoaded()` antes de parsear;
- parsea con `cliOptionRegistry().parse(...)`;
- genera el `--help` recorriendo las opciones registradas;
- aplica las variables de entorno del resultado;
- conserva los códigos de salida: 0 para ayuda, 1 para opción desconocida,
  refresh inválido, sin proyecto o más de un proyecto.

## 3. Tests

`src/lib/utility/commandline/tests/CliOptionRegistryTest.cpp`:

- registro y parseo de dos opciones de prueba;
- propagación de errores de validación;
- opción desconocida;
- `removeOption` y posterior parseo como desconocida;
- carga del manifiesto real con `unloadable=true` (sólo en el test), cinco
  opciones registradas y eliminación completa al descargar el plugin.

## 4. Verificación funcional

| Prueba | Resultado |
|---|---|
| `sourcetrail_cli --help` | lista las cinco opciones |
| `--bogus` / `--refresh=bogus` / sin proyecto / dos proyectos | exit **1** |
| `--help` | exit **0** |
| Odin sample con `--refresh=all --threads=1` (desktop) | **32 / 42 / 0** |
| Odin sample con las mismas opciones (embedded) | **32 / 42 / 0** |
| `tictactoe_cpp` | **383 / 819 / 0** |
| `tutorial-py` completo | **103 / 264 / 0** |
| `tutorial-py` con `--python-shallow` | **100 / 187 / 0** (la opción se aplica) |
| Plugins | **3/3** |
| Registro de lenguajes | **1/1** |
| Indexador Odin | **7/7** |
| Graphify | **27.678 nodos / 81.419 aristas / 767 comunidades** |

La diferencia entre el modo Python completo y shallow confirma que
`--python-shallow` llega al indexer; no es una regresión.

## 5. Pendiente de F5

- **GUI**: acciones de menú/toolbar, páginas de preferencias, contenido del
  wizard y paneles como efectos reversibles.
- **Listeners de mensajes**: `registerListener`/`unregisterListener` existen,
  pero los objetos Qt se registran en sus constructores.
- **Perfiles de composición**: `embedded`, `desktop`, `cli-cxx`, `cli-java`.
- El plugin `cli-options` es `unloadable=false` en producción; el test fuerza
  `true` para ejercitar la inversa.

## 6. Reproducir

```powershell
cmake --build build --config Release --target sourcetrail_cli
build\Release\app\sourcetrail_cli.exe --help
build\Release\app\sourcetrail_cli.exe --refresh=all --threads=1 `
  bin\app\user\projects\odin-sample\odin-sample.srctrlprj

cmake -S src/lib/utility/commandline/tests -B _study/cli-options-test `
  -G "Visual Studio 18 2026" -A x64
cmake --build _study/cli-options-test --config Release
ctest --test-dir _study/cli-options-test -C Release --output-on-failure

cmake --build build-embedded --config Release --target sourcetrail_cli
build-embedded\Release\app\sourcetrail_cli.exe --refresh=all --threads=1 `
  bin\app\user\projects\odin-sample\odin-sample.srctrlprj
```
