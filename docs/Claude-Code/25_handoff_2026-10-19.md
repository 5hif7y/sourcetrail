## 8. Trampas conocidas

- Si `ODIN_EMPTY` no está en la rama de `Project.cpp` que usa
  `TaskExecuteCustomCommands`, el core intenta IPC y falla con “type unknown”.
- El indexador nativo necesita el `.lib` al compilar y la DLL junto al `.exe` al
  ejecutar.
- El build script despliega a `bin/app/data/odin` y a los builds; `copyAppData` sólo
  copia si el directorio existe en configure time.
- La DB temporal del core ya existe cuando el worker la abre; no crear una DB nueva
  con otro nombre.
- El writer C++ deduplica member edges; no comparar aristas totales con Python sin
  filtrar el tipo 1.
- `SOURCETRAIL_ODIN_NATIVE_INDEXER` apuntando a una ruta inexistente fuerza el fallback
  Python (útil para comparar).
- El compilador Odin de este host es `C:\Software\Odin-oct-2026\odin.exe`; el build
  script acepta `-Odin`.
- El writer depende de `sourcetrail-db` hermano; si no está, pasar
  `-DSOURCETRAILDB_DIR`.
