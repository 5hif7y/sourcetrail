
### Flags de auditoría del indexador

- `--unsolved` (o `SOURCETRAIL_ODIN_UNSOLVED=1` en el core): registra no
  resueltas.
- `--timing` (o `SOURCETRAIL_ODIN_TIMING=1`): fases por archivo/lote al stderr.
- `--debug-refs`: imprime imports y cada referencia con su resolución.
- `--no-unsolved`: compatibilidad; hoy es el default.

## 8. Trampas conocidas

- `%{SOURCE_FILE_PATH_ARGS}` sólo existe en el template nativo; el fallback
  Python sigue con `%{SOURCE_FILE_PATH}` y un archivo por proceso.
- `MemoryIndexerCommandProvider` mapea cada archivo del lote al mismo comando;
  consumir uno consume el lote entero y el progreso avanza por archivos.
- `---` se lexa como tres `-`: no buscar el token `"---"`.
- `skip_directive` consume hasta el newline (sirve para `#+build` de nivel
  superior); dentro de declaraciones usar `skip_token_directive`.
- `@private` sin paréntesis: `skip_attribute` debe consumir el nombre.
- Las no resueltas están apagadas por defecto; si un test espera el nodo
  `unsolved symbol`, pasar `--unsolved`.
- El writer deduplica member edges; comparar aristas totales con Python sin
  filtrar tipo 1 confunde.
- `SOURCETRAIL_ODIN_NATIVE_INDEXER` inexistente fuerza el fallback Python.
- El compilador Odin de este host está en
  `C:\Software\Odin-oct-2026\odin.exe`.
- `PluginHost` guarda el id antes de mover el manifiesto (orden de evaluación
  de `emplace`).
- `ensureOdinPluginLoaded()` usa un host estático deliberadamente vivo todo el
  proceso; la descarga se prueba en `plugin_host_test`.
